# Security

Chaoxing Video Helper is a playback convenience userscript.

Please do not use this project to bypass captchas, quizzes, exams, sign-ins, attendance checks, or platform protections.

## Reporting Issues

Open a GitHub issue with enough information to reproduce the problem. Do not include:

- account passwords
- cookies
- private course links
- personal identifiers
- screenshots containing private course data

## Permissions

The script uses a broad userscript match rule because Chaoxing video players are often embedded in nested frames from different hosts. It exits immediately unless the current page URL or referrer looks related to Chaoxing/Xueyin.
